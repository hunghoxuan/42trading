- Read fresh.
- Use `rtk` for shell.
- Keep boot small.
- Load only task-needed docs.
- Test real code changes.
- Do not create new files in `scripts/` or `tests/` without explicit user request and approval.
- Put scratch, one-off, and AI-only helper files in `.local/`.
